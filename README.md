# Brock Burchett portfolio

Next.js, React, and TypeScript. Node.js 22.13+.

Run `npm install`, then `npm run dev`. Build with `npm run build`.

Import the repository into Vercel using the Next.js preset. No environment variables or database are required. Add brockburchett.com in Vercel domain settings and use its DNS records.

Content: app/page.tsx. Styling: app/globals.css.
